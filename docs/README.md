# Media Gen documentation

- [Getting started](getting-started.md): install Media Gen, initialize a
  project, connect Microsoft Foundry, and start the Local UI.
- [Agent-first workflows](agent-workflows.md): install the `generate-media`
  skill and delegate setup, creation, iteration, and export to an agent.
- [Creating and managing media](creating-media.md): use Generators, Scenarios,
  references, Styles, Presets, and Generation history.
- [CLI reference](cli-reference.md): command syntax, options, and examples.
- [Storage and privacy](storage-and-privacy.md): understand what is stored,
  shared, sent to providers, and exported.

Media Gen is an early prototype. Run `mg <command> --help` for the command
contract implemented by the installed version.
