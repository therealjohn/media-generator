# Keep Speech configuration private and separate from deployments

Azure Speech voices are not Foundry Model Deployments, so Media Gen stores the regional Speech synthesis endpoint, API key, and default Voice in the machine-local Local Profile. The endpoint uses `https://<region>.tts.speech.microsoft.com/`; the general Cognitive Services resource URL is not a synthesis endpoint. Endpoint and Voice updates retain the saved key when no replacement is supplied. CLI Explainer requests default to Auto Voice, which resolves that private default. The Local UI selects the configured default Voice by name; selecting Off omits the `voice` role. Foundry discovery remains limited to deployable model resources, while Settings and `mg configure speech` expose only non-secret Speech status after saving the key.
