# Support

Media Gen is an early, community-maintained prototype without a support SLA.

## Usage questions

Use GitHub Discussions when it is enabled. Otherwise, open an issue using the
closest available template. Before posting:

1. Read the [README](README.md) and command-specific `--help`.
2. Run `mg doctor`.
3. Search existing issues for the same symptom.

Include the Media Gen version, Node.js version, operating system, relevant
command, and a minimal reproduction. Redact account details, local paths,
provider resource names, Creative Briefs, Reference Sources, and generated
media unless they are safe to share publicly.

## Bugs and feature requests

Use the issue forms for reproducible Media Gen defects and feature proposals.
Provider outages, quota, account access, and Microsoft-hosted service behavior
may require support from the relevant service owner.

## Security and conduct

Do not report vulnerabilities, exposed credentials, private data, or conduct
incidents in a public issue. Follow [SECURITY.md](SECURITY.md) for security
reports and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct reports.
